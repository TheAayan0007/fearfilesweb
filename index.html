FEAR

Encrypt, read, and decrypt one or many files locally in your browser. FEAR uses authenticated AES‑256‑GCM, a hardened password KDF, and chunked processing so large files are handled more safely.

Security note: This build is hardened, but it has not been professionally audited. Keep your password unique and use a long passphrase. FEAR cannot recover a forgotten password.

Encryption: AES‑256‑GCM with random per-file salt/nonce and authenticated chunks. Passwords are processed with PBKDF2-HMAC-SHA256 at 1,200,000 iterations in this browser-only build because Web Crypto does not provide Argon2id natively.

Password policy: at least 16 characters; common passwords and obvious repeated-character patterns are rejected. A unique 20+ character passphrase is strongly recommended.

There is no password recovery. If you forget a password, the encrypted file cannot be opened without it.

Large-file handling: Chromium/Edge can stream encrypted/decrypted output directly to a file via the Save dialog; browsers without the File System Access API use a Blob fallback. The Read viewer still needs the unlocked content available to the browser.

Security status: no independent professional security audit is claimed. Treat this as security software that still needs external review before high-stakes use.

This is a separate, browser-based tool and its file format isn't compatible with the FEAR desktop app.
